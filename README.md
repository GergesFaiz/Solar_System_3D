# 🌌 Solar System 3D Explorer

An interactive and immersive 3D Solar System exploration mobile application built using **Flutter** and **model_viewer_plus**. The app allows space enthusiasts and learners to explore planets and celestial bodies with real-time 3D rendering, interactive controls, and comprehensive astronomical facts.

---

## 🚀 Features

- **Interactive 3D Planetary Models**: Rotate, zoom, and examine high-fidelity 3D models (`.glb`) of celestial bodies in real time.
- **Deep Space Exploration**: Detailed astronomical specifications for each planet:
  - Distance from the Sun
  - Length of day & Orbital period
  - Radius, mass, gravity, and surface area
- **Sleek Space UI/UX**: Dark cosmic theme crafted with fluid transitions and responsive layouts.
- **Swipe Navigation**: Intuitive carousel slider to browse smoothly across all planets in our solar system.

## 🏁 Getting Started

### Prerequisites

- Flutter SDK (>= 3.9.0)
- Android Studio / VS Code
- Android Device or Emulator (Android API 24+ recommended for optimal 3D WebView performance)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/GergesFaiz/Solar_System_3D.git
   cd Solar_System_3D
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the application:**
   ```bash
   flutter run
   ```
